# E-Commerce Sales Dashboard – Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze e-commerce sales performance, profitability and customer purchasing trends.

## Tools & Technologies
- Power BI
- Power Query
- DAX

## Key Features
- Total Sales, Total Profit and Total Quantity KPIs
- Sales analysis by state and category
- Payment mode analysis
- Top 5 customers by sales
- Monthly profit trends
- Interactive City and Month slicers
